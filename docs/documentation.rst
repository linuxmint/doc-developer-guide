#########################
Documentation Guidelines
#########################

Simplistic
==========

According to a `2017 paper published by OECD <https://www.oecd.org/en/publications/computers-and-the-future-of-skill-demand_9789264284395-en.html>`_, only about 20% of the human adult population have proficient digital literacy when interacting with local systems. 

Unfortunately, as a result, When you write documentation for end users, like in the install and user guide, **Write pages as simply as possible.**

1. Make each paragraph at max 1-2 lines, most people will merely gloss over every single paragraph, regardless of length.
2. Use bulleted lists to give easy to understand actions a person can take with easy to understand language.
3. It is hard to hit the right balance, but do not talk down to the end user.

Actionable
===========

People like direct instruction, It's true!

Whenever possible, Phrase it in a way that can be acted upon immediately without any interpretation.

It should read like an a business dealing. Authoritative, and direct; giving directions for a person to do.

Example
--------

Change the text inside a file named FileMcFileface.txt to "cat"

*Wrong*: "You should find a file named 'FileMcFileface', Nextly, you should open it and change the text to 'cat'."

*Right*: "When you open the 'Folderhead' folder, Open the file named 'FileMcFileface.txt'.
Delete all the text inside it and type 'cat' before saving."

Usable
=======

Whenever possible, try to encourage the use of already built-in tools and programs. A person should not *need* to use external software to fix problems with the operating system. 

One of the goals of Mint as an operating system is to be working straight out of the box, So giving priority to something that isn't from said box isn't exactly a good image. 

However, You can mention benefits that can come from the usage of external software, as to give the end user courage to try something new.

Regarding Screenshots
======================

A unified look is encouraged for looking coherent, remaining understandable, and staying fresh.

Theming settings should be set to: 

- Mint-L style
- Light appearance
- Green color

It is encouraged that you use a separate user profile for taking screenshots as to conceal your identity.

IRC and Discord 
----------------

The *Matrix* application on your computer automatically joins you into the Linux Mint server when you sign up for an account. The Linux Mint Developers channel is willing to answer most questions you may have about a specific program or procedure.

The `Linux Mint Community Discord <https://discord.com/invite/mint>`_ is a great resource for finding up to date information and real cases.
